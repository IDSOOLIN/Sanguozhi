# 三国抽卡簿｜iPhone 版功能清单

## 1. 产品定位

为《三国志·战略版》玩家提供一个简单、清晰的抽卡记录工具，用于记录每次抽卡结果，查看出卡概率、保底进度和赛季抽卡数据。

首个版本仅支持 iPhone，数据默认保存在本机，不需要登录游戏账号。

## 2. 首版 MVP 功能

### 2.1 首页

- 显示当前赛季
- 显示本赛季累计抽卡次数
- 显示五星武将获得数量
- 显示个人五星出卡率
- 显示当前保底进度
- 显示距离下一次保底所需抽数
- 展示最近 5 条抽卡记录
- 提供“记一抽”快捷入口

### 2.2 手动记录抽卡

- 输入武将名称
- 选择武将星级
  - 五星
  - 四星
- 输入或选择卡包名称
- 自动记录抽卡日期和时间
- 自动归入当前赛季
- 保存记录
- 未填写武将名称时禁止保存

### 2.3 抽卡记录

- 查看全部抽卡记录
- 按抽卡时间倒序排列
- 每条记录显示：
  - 武将名称
  - 武将星级
  - 卡包名称
  - 抽卡日期
- 区分五星和四星武将的视觉样式

### 2.4 数据统计

- 统计累计抽卡次数
- 统计五星武将数量
- 自动计算五星出卡率
- 根据抽卡次数计算保底进度
- 新增记录后自动更新统计结果

### 2.5 本地数据

- 抽卡记录保存在 iPhone 本机
- 关闭 App 后数据不丢失
- 不采集游戏账号或密码
- 无网络时仍可使用基础功能

## 3. 建议在第二版增加的功能

### 3.1 记录管理

- 编辑已有记录
- 删除错误记录
- 批量补录抽卡结果
- 单抽与五连抽模式
- 添加备注
- 标记核心武将
- 标记重复武将

### 3.2 筛选与搜索

- 按武将名称搜索
- 按赛季筛选
- 按卡包筛选
- 按星级筛选
- 按日期范围筛选
- 只查看五星或核心武将

### 3.3 统计分析

- 各卡包抽卡次数和五星率
- 各赛季抽卡次数和五星率
- 平均多少抽获得一个五星
- 连续未出五星的最大抽数
- 核心武将获得率
- 重复武将次数排行
- 日、周、月抽卡趋势

### 3.4 赛季与卡包管理

- 创建和切换赛季
- 设置当前赛季
- 添加自定义卡包
- 管理常用卡包
- 分赛季保存统计数据

### 3.5 数据安全

- 导出抽卡记录
- 导入历史记录
- iCloud 备份与恢复
- 更换 iPhone 后恢复数据

## 4. 后续高级功能

### 4.1 截图识别

- 从相册选择抽卡截图
- 自动识别武将名称和星级
- 用户确认后批量保存
- 对无法识别的结果提供手动修正

### 4.2 武将图鉴

- 查看武将列表
- 查看已获得和未获得武将
- 统计每位武将获得次数
- 设置目标武将或心愿武将
- 展示武将阵营、兵种和标签

### 4.3 个性化

- 深色模式
- 自定义首页统计卡片
- 自定义保底抽数规则
- App 图标和主题皮肤
- 抽到目标武将时提供动效和提示

### 4.4 分享

- 生成抽卡战报图片
- 分享单次抽卡结果
- 分享赛季统计报告
- 隐藏敏感信息后分享

## 5. 页面规划

| 页面 | 主要内容 | 首版是否包含 |
| --- | --- | --- |
| 首页 | 数据概览、保底进度、最近记录 | 是 |
| 新增记录 | 武将、星级、卡包录入 | 是 |
| 记录列表 | 全部抽卡历史 | 是 |
| 统计 | 趋势、卡包、赛季分析 | 基础统计 |
| 武将图鉴 | 武将收集情况 | 否 |
| 我的 | 赛季、数据备份、设置 | 否 |
| 截图识别 | 从截图批量导入 | 否 |

## 6. 首版验收标准

- App 可以在 iPhone 上正常启动
- 用户可以新增一条四星或五星抽卡记录
- 新增的记录会立即显示在首页和记录列表
- 累计抽数、五星数量、五星率和保底进度计算正确
- 退出并重新打开 App 后，已有记录仍然存在
- 页面内容不被刘海、灵动岛或底部 Home Indicator 遮挡
- 输入时键盘不会遮挡保存按钮
- 没有网络时仍可新增和查看记录

## 7. 首版暂不包含

- Android 版本
- iPad 专用布局
- 游戏账号登录
- 自动读取游戏数据
- 云端账号体系
- 玩家社区和排行榜
- 付费、会员或广告功能
- 自动截图识别

## 8. 开发优先级

1. 完成首页和本地数据模型
2. 完成手动新增抽卡记录
3. 完成记录列表
4. 校验统计及保底计算
5. 适配不同尺寸的 iPhone
6. 真机测试和首版打包
